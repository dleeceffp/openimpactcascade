feat(search): add provider fallback chain for resilient web search

Adds transparent failover so web search continues when the primary provider
hits quota, rate limits, or a transient outage — invisible to end-users.

oic_search/base.py
- Added fallback_providers: List[str] field to SearchConfig (default []).
  Holds the ordered fallback chain; auth/not_configured failures do NOT
  trigger it (they indicate misconfiguration, not transience).

oic_search/config.py
- Reads OIC_SEARCH_FALLBACK env var (comma-separated) and validates each
  entry against the known provider list at load time.
  Example: OIC_SEARCH_FALLBACK=brave

oic_search/__init__.py
- Added search_with_fallback(): tries primary provider, catches transient
  errors (quota, rate_limit, timeout, unknown), logs the switch, and retries
  with the next provider in the chain.  Permanent failures (auth,
  not_configured) propagate immediately without trying fallbacks.
  Cache check/store applies per provider; a cache hit short-circuits the chain.
- Exported in __all__.

app/ai_question_generator.py
- __init__ now resolves self.search_fallback_providers from OIC_SEARCH_FALLBACK
  env var (already loaded by config.py bootstrap) and logs the full provider
  chain at startup: "Web search enabled — provider chain: tavily → brave".
- _execute_search() calls search_with_fallback() instead of search(), passing
  the resolved chain; the fallback is entirely transparent to prompt assembly.
- Exhausted-chain error logs the full chain for observability.

deployment/gcp/deploy_infrastructure.sh
- Added OIC_SEARCH_FALLBACK to both SECRETS[] and REQUIRED_SECRETS[] with a
  safe interactive default of "brave".
- Both TAVILY_API_KEY and BRAVE_SEARCH_API_KEY are now provisioned by default
  (BRAVE_SEARCH_API_KEY remains skippable but warns that failover is lost).
- OIC_SEARCH_FALLBACK prompt shows default value and accepts Enter-to-default.
- Dynamic --set-secrets builder mounts OIC_SEARCH_FALLBACK; BRAVE_SEARCH_API_KEY
  still conditionally mounted only when its secret exists.

Typical production configuration:
  OIC_SEARCH_PROVIDER=tavily
  OIC_SEARCH_FALLBACK=brave
  TAVILY_API_KEY=tvly-...
  BRAVE_SEARCH_API_KEY=BSA...
