# Code Generator Tracking

## Overview

The user tracking system now includes a **code generator identifier** to distinguish between different code implementations during testing. This is particularly useful when comparing code generated by different AI assistants or development approaches.

---

## Implementation

### User ID Format

**Before:**
```
eval-user-a1b2c3d4e5f6
```

**After:**
```
eval-{code_generator}-a1b2c3d4e5f6
```

**Example with WSA (Windsurf Anthropic):**
```
eval-wsa-a1b2c3d4e5f6
```

---

## Code Generator Identifiers

| Identifier | Meaning | Use Case |
|------------|---------|----------|
| `wsa` | Windsurf Anthropic | Code generated by Windsurf with Anthropic (default) |
| `custom` | Custom identifier | User-defined for specific testing scenarios |

**Note:** You can use any string identifier to distinguish between code trees during testing.

---

## Usage

### In user_tracking.py

```python
# Create tracker with code generator identifier
tracker = get_tracker(session_based=True, code_generator="wsa")

# User ID will be: eval-wsa-{random_hex}
user_id = tracker.get_user_id()
```

### In Flask Application

```python
from user_tracking import get_tracker

# Get tracker with WSA identifier (default)
tracker = get_tracker(session_based=True, code_generator="wsa")
user_id = tracker.get_user_id()

# Or use a different identifier for comparison
tracker_alt = get_tracker(session_based=True, code_generator="other")
```

## Changing the Identifier

### For Different Code Trees

If testing a different implementation:

```python
# In your Flask app initialization or config
CODE_GENERATOR = "competitor_ai"  # or "manual", "legacy", etc.

# Pass to tracker
tracker = get_tracker(session_based=True, code_generator=CODE_GENERATOR)
```

### Environment Variable (Optional)

You could also make this configurable:

```python
import os

CODE_GENERATOR = os.environ.get('CODE_GENERATOR', 'wsa')
tracker = get_tracker(session_based=True, code_generator=CODE_GENERATOR)
```

Then run:
```bash
export CODE_GENERATOR=wsa
python flask_app_chat.py
```

## Investigation by Code Generator

### Using investigate_abuse.py

Search for users by code generator:

```bash
# Find all WSA users
grep "eval-wsa-" ./logs/api_calls/*.jsonl

# Get stats for a specific WSA user
python investigate_abuse.py --user-id eval-wsa-a1b2c3d4e5f6 --stats
```

### Custom Analysis

```python
import json
from glob import glob

# Count calls by code generator
code_gen_counts = {}

for log_file in glob('./logs/api_calls/*.jsonl'):
    with open(log_file, 'r') as f:
        for line in f:
            log = json.loads(line)
            user_id = log.get('user_id', '')
            
            # Extract code generator from user_id
            if user_id.startswith('eval-'):
                parts = user_id.split('-')
                if len(parts) >= 3:
                    code_gen = parts[1]
                    code_gen_counts[code_gen] = code_gen_counts.get(code_gen, 0) + 1

print("API Calls by Code Generator:")
for code_gen, count in sorted(code_gen_counts.items()):
    print(f"  {code_gen}: {count} calls")
```

## Default Behavior

**If no code_generator is specified:**
- Defaults to `"wsa"` (Windsurf Anthropic)
- Maintains backward compatibility
- All existing code continues to work

**Example:**
```python
# These are equivalent:
tracker1 = get_tracker(session_based=True)
tracker2 = get_tracker(session_based=True, code_generator="wsa")
```

## Best Practices

1. **Use Descriptive Identifiers**
   - `wsa` - Windsurf Anthropic
   - `manual` - Manually written code
   - `legacy` - Previous implementation
   - `v1`, `v2` - Version numbers

2. **Keep Identifiers Short**
   - 2-10 characters recommended
   - Lowercase preferred
   - Use hyphens for multi-word: `wsa-exp`

3. **Document Your Identifiers**
   - Maintain a list of active identifiers
   - Note what each represents
   - Include in testing documentation

4. **Consistent Usage**
   - Use the same identifier throughout a code tree
   - Don't mix identifiers in a single deployment
   - Change only when comparing implementations
